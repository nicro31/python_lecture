This digital textbook is an introduction to Python, with a focus on chemistry related problems. It is intended to be a one-stop-shop where you can access all of the educational materials used during the course taught in the Chemistry Master's program at the University of Lille.

It is not intended to be an exhaustive presentation to Python, and it is not a lecture dedicated to future software programmers either (which I am not by the way). Instead, the aim of this lecture is to provide to the typical chemistry student (or anyone else) the tools to be able to quickly develop a program to solve a given problem. 

Finally, it is worth questioning whether teaching Python courses remains necessary in light of the incredible programming abilities of Artificial Intelligence? As I write these lines (2026), I still think yes, at least to know where to start from: what should I install on my computer to do some programming, what are the possibilities offered by Python, and how does a program works under the hood. AI is an amazing tool for programming, and just anyone can produce very complex programs nowadays in a couple of hours. Therefore, I definitely encourage the use of AI for programming, but I believe that one must know the basics of programming to really get the best out of it.

## Textbook content

The lecture is essentially based on **Active Learning**, meaning that you will be actively involved and doing something besides passively listening or watching. In particular, you will have to read many things by yourselves, and you will have the occasion to verify your understanding all along the way with exercices. These exercices always include a solution, and you may also be able to solve them in a couple of seconds using AI. Yet I encourage you to spend sometimes trying to solve them by yourself, as this is (in my opinion) the only way to progress and get a deep understanding of Python.  

The textbook is divided into 5 sections:
1. The first section, {ref}`Get Started <content:GetStarted>`, will show you how to set up everything you need to start coding with Python.
2. Section {ref}`Variables and Operations <content:SimpleVariables>` introduces the very basics of Python and programming in general.
3. In section {ref}`Structuring a Program <content:ConditionsAndLoops>`, you will discover the fundamental elements to implement your first complete program.
4. Section {ref}`Libraries, Packages and Modules <content:Fundamentals>` will show you how to solve complex problems, in sciences and chemistry in particular, using Python libraries.
5. The last section, {ref}`Projects <content:IntroductionAndInstructions>`, is a list of programming project submitted to the students. Working of one of these project is a good way to improve your skills.

## Using the textbook

You can use the navigation panel on the left to jump quickly between sections of this textbook, even though it is intended to be read in the order of the sections. You can also use the navigation panel on the right to jump between the sub-sections of a given section.
You will have to complete many exercices during this lecture. To do so, I advise you to use what we call a **Jupyter Notebook**: this tool will be presented in the first section, {ref}`Get Started <content:GetStarted>`.
